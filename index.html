Offline data on this device

Firebase Firestore can keep synchronized portfolio data and queued changes in this browser’s IndexedDB. This is separate from the public app shell.

  • Enable this only on a trusted personal device. It can include private project drafts and booking contact details.
  • Do not enable it on a shared device. Sign out when finished; Firebase authorization is still checked by Firestore when changes sync.
  • Browser site-data cleanup can erase local data and pending work. Turning this off affects future sessions; it does not securely erase existing browser storage.
  • File uploads, sign-in, notifications, WhatsApp, and media playback still need an internet connection.

Saved project changes and R2 cleanup records require the authorized owner account. Media paths are checked against Firestore before files are removed. Download a review copy before discarding unresolved changes.
